Why bouine?

RFC 9111 native
84.7% on cache-tests. Vary, conditional revalidation, stale-while-revalidate, stale-if-error — all built in.
No external KV
Embedded SIEVE hot tier in RAM plus optional mmap warm tier. No Redis, no Memcached.
Zero-alloc hit path
100 ns/op, 0 allocs on cache hits. Benchmark-gated CI blocks regressions automatically.
Observability first
Prometheus metrics, OpenTelemetry traces, structured JSON access logs with cache_status, pprof.
Precise invalidation
Purge by URL, predicate bans, soft-purge refresh. Broadcast to all cluster peers automatically.
Kubernetes native
Helm chart, StatefulSet gossip, PodDisruptionBudget, NetworkPolicy, ServiceMonitor — all included.

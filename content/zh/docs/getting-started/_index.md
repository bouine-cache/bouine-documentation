本节将带您从零到一个可运行的缓存。您将：

1. 安装或运行 bouine。
2. 启动一个小型源站服务器。
3. 将 bouine 放在其前面。
4. 验证 `MISS`，然后 `HIT`。

## 页面

- [安装](install/) — Docker、二进制文件和从源码编译。
- [快速开始](first-cache/) — 启动源站、配置 bouine 并验证缓存命中。
- [Docker](docker/) — 运行和构建镜像。
- [Kubernetes](kubernetes/) — 使用 Helm 和 StatefulSet gossip 部署。
- [配置示例](examples/) — 静态站点、API 网关和电商示例。

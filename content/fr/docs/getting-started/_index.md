Cette section vous fait passer de zéro à un cache fonctionnel. Vous allez :

1. Installer ou exécuter bouine.
2. Démarrer un petit serveur d'origine.
3. Placer bouine devant celui-ci.
4. Vérifier `MISS`, puis `HIT`.
